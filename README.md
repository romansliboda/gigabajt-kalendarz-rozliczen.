# Gigabajt — Kalendarz rozliczeń (wersja web)

Wersja do testowania na telefonie w przeglądarce przez GitHub Pages. **To nie jest projekt APK**.

## Uruchomienie przez GitHub Pages
1. Wgraj `index.html` do katalogu głównego nowego repozytorium `gigabajt-kalendarz-rozliczen`.
2. W repozytorium wybierz Settings → Pages → Build and deployment → Deploy from a branch.
3. Ustaw Branch `main` i folder `/ (root)`, a następnie Save.
4. Po opublikowaniu otwórz `https://romansliboda.github.io/gigabajt-kalendarz-rozliczen/`.

Dane zapisują się lokalnie w przeglądarce (`localStorage`), a nie na GitHubie. Eksport PDF: przycisk „Zapisz w PDF” otwiera drukowanie, gdzie można wybrać „Zapisz jako PDF”. Klawisz Enter/✓ obsługiwany jest w polach wpisów; zachowanie klawiatury zależy od przeglądarki Android.
