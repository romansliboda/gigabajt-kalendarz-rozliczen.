TrafficBan w oknie poniżej nie udostępnia aplikacji danych do odczytu. Można zaimportować oddzielny, zweryfikowany plik JSON z przedziałami zakazów. Bez niego ciężarówka pozostaje szara. Import nie jest pobieraniem danych z TrafficBan.

Format danych
{"updatedAt":"2026-10-19T08:00:00Z","validUntil":"2026-10-20T08:00:00Z","coverage":[{"country":"DE","vehicleMinTonnes":7.5,"complete":true}],"bans":[{"country":"DE","start":"2026-10-19T10:00:00+02:00","end":"2026-10-19T22:00:00+02:00","vehicleMinTonnes":7.5}]}
